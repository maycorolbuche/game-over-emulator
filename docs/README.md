## Manutenção obrigatória

Atualize estes guias junto com mudanças de comportamento, configuração, dependências, comandos, catálogo, controles, armazenamento ou publicação. Mantenha o README como entrada curta e use os guias para detalhes. Registre na PR os documentos alterados e as verificações realizadas.

Se a alteração não modificar nenhuma informação documentada, registre a justificativa na PR em vez de fazer mudanças cosméticas. Não inclua segredos, tokens ou valores de credenciais em exemplos.
